Como conectar no Power BI Desktop

  1. Gere um token acima Clique em "+ Gerar token", dê um nome identificável (ex.: "Power BI Relatórios") e copie o valor exibido.
  2. Abra o Power BI Desktop No menu Página Inicial, clique em Obter Dados → Feed OData.
  3. Cole a URL do endpoint Use um dos endpoints exibidos acima, com o token gerado já incluído.
    {% if pode_pedidos %}Exemplo: {% endif %}
  4. Autenticação Quando solicitado, escolha Anônima — a autenticação já está embutida na URL via token.
  5. Carregue e modele os dados Clique em Carregar (ou Transformar Dados se quiser ajustar colunas). Os dados são atualizados automaticamente a cada hora pelo sistema.
Dica: No Power BI, configure a Atualização Agendada do relatório para replicar automaticamente a frequência de sync do sistema (a cada 1 hora).
