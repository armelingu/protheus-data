Ajuda

Como conectar no Power BI Desktop

Passo a passo para importar os dados pelo feed OData.
  1. Gere um token nesta página Dê um nome identificável (ex.: "Power BI Controladoria") e clique em Gerar token. Uma caixa verde aparece com as URLs já montadas — copie a do relatório desejado.
  2. Abra o Power BI Desktop No menu Página Inicial, clique em Obter Dados → Feed OData.
  3. Cole a URL do endpoint na caixa "URL" Use a URL copiada da caixa verde — ela já inclui o token de autenticação.
  4. Escolha "Anônima" na etapa de autenticação O Power BI pedirá como autenticar — selecione Anônima e clique em Conectar. A autenticação já está embutida na URL pelo token.
  5. Carregue os dados Clique em Carregar para importar diretamente, ou em Transformar Dados para ajustar colunas antes. Os dados refletem o último sync do sistema.
  6. Configure a atualização agendada No Power BI Desktop, vá em Página Inicial → Atualizar a qualquer momento para puxar os dados mais recentes. Para atualização automática no Power BI Service (online), é necessário um gateway de dados — consulte o TI, pois o sistema roda em rede interna.
Horário de sincronização: os dados são atualizados automaticamente de hora em hora entre 8h e 19h nos dias úteis. Atualizações no Power BI fora desse horário trazem o último cache — não há dados novos do Protheus nesse intervalo.

Ajuda

Como conectar no Excel (Power Query)

Mesma URL do token, pelo Power Query do Excel.
  1. Gere um token e copie a URL Use a caixa verde após gerar o token. A URL vale também no Excel.
  2. No Excel, abra o Power Query Vá em Dados → Obter Dados → De Outras Fontes → Do Feed OData.
  3. Cole a URL e conecte Cole a URL copiada e clique em OK. Quando solicitado, escolha Anônima como método de autenticação.
  4. Carregue a tabela No painel do Power Query, selecione a tabela de dados e clique em Fechar e Carregar. Para atualizar, clique com o botão direito na tabela e selecione Atualizar.
Ao revogar um token: qualquer conexão do Power BI ou Excel que usa aquele token deixa de funcionar na hora. Com um token substituto, atualize a URL da fonte de dados em cada relatório ou pasta de trabalho.
